# PR.-4 Functional Treat
 
## Description
This project demonstrates the use of Python functions to perform different tasks and improve code reusability. It helps beginners understand how functions work and how they can organize programs effectively.
 
## Functions Used
- `def` - To create user-defined functions.
- Function Parameters - To pass values into functions.
- `return` Statement - To send results back from functions.
- Function Calls - To execute specific tasks.
- Input Functions - To take user input.
- Output Functions - To display results.
 
## Features
- Modular and reusable code
- Function-based programming approach
- User input handling
- Result generation using functions
- Beginner-friendly implementation
- Easy to read and maintain code
 
## Learning Outcomes
Through this project, you will learn:
- How to create functions
- How to pass arguments to functions
- How to use return values
- How to improve code organization
- Basic problem-solving using functions
