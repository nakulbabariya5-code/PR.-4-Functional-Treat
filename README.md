README – Data Analyzer and Transformer

About

This is a Python project used to analyze and transform numerical data using different functions.

Functions and Concepts Used

- List Functions: "append()", "count()", "sort()"
- Built-in Functions: "len()", "min()", "max()", "sum()", "type()"
- Functional Tools: "lambda", "filter()", "map()"
- Recursion: "factorial()", "fibonacci()"
- User-Defined Functions: "input_data()", "display_summary()", "sort_data()"
- Arguments: "*args", "**kwargs"
- Other Concepts: Global variables, loops, conditional statements, 1D and 2D lists, dictionaries, and functions returning multiple values.
